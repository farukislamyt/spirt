# Security Policy

## Scope

SPIRT is designed for research on legitimately public information and authorized official APIs.

Do not use SPIRT to bypass authentication, private-profile restrictions, anti-bot systems, access controls, rate limits, or other platform protections. Do not use it to collect credentials, session tokens, or private data.

## Reporting a vulnerability

Please report security vulnerabilities privately through the repository's GitHub security reporting mechanism rather than opening a public issue with exploit details.

Include enough information to reproduce the issue safely, including the affected version, component, impact, and a minimal reproduction when possible.

## Supported versions

Security fixes target the latest stable release. Users should keep SPIRT updated to the latest release and its dependencies.
