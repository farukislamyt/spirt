SPIRT — Social Profile Intelligence Research Toolkit

Open-source Python tooling for public-profile OSINT, evidence-first collection, cross-platform correlation, and research reporting.

Public-profile OSINT, without access-control bypass

SPIRT discovers supported profile URLs, collects legitimately public metadata, normalizes fields, preserves provenance, correlates explicit signals, and produces JSON, Markdown, or HTML reports.

Core pipeline

Provider → Collector → Parser → Normalizer → Evidence → Output
