# TikTok OSINT Provider

The TikTok provider handles supported public profile URLs using public-web metadata.

## Scope

SPIRT extracts only metadata that is exposed publicly and normalizes it into the common profile model with provenance where available.

## Limitations

Public page behavior can vary by region, consent state, and platform changes. SPIRT does not bypass authentication, private profiles, anti-bot controls, or access restrictions.
