GitHub Profile OSINT Provider

SPIRT supports public GitHub profile research through its provider architecture, with normalized profile fields and evidence provenance.

Research model

  • Public profile URL collection
  • Metadata normalization
  • Evidence-backed fields
  • Cross-platform signal analysis
  • JSON, Markdown, and HTML reporting

Boundary

Only public information is in scope. SPIRT does not bypass authentication, private repositories or profiles, access controls, anti-bot protections, or rate limits.
