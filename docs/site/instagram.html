Instagram Profile OSINT Provider

SPIRT provides a public-web metadata collection path for supported Instagram profile URLs, with deterministic normalization and evidence provenance.

Research model

  • HTTPS-only provider routing
  • Public metadata collection
  • Stable normalized fields
  • Evidence attached to collected values
  • Graceful unavailable/failed results

Limitations

Public availability can change. SPIRT does not bypass authentication, private profiles, anti-bot controls, or rate limits.
