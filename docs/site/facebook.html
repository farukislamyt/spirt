Facebook Profile OSINT Provider

SPIRT can route supported Facebook profile URLs to its public-web metadata provider. Collection is limited to information legitimately exposed without authentication bypass.

Research model

  • HTTPS profile URL validation
  • Public metadata parsing
  • Deterministic normalization
  • Field-level evidence provenance
  • Structured collection status and errors

Limitations

Availability and fields depend on what Facebook exposes publicly at collection time. SPIRT does not bypass login, privacy controls, anti-bot protections, or rate limits.
