X / Twitter Profile OSINT Provider

SPIRT supports public-web collection for supported X/Twitter profile URLs, producing structured results that can be correlated with other public profiles.

Research model

  • Strict provider URL validation
  • Public metadata parsing
  • Deterministic normalization
  • Evidence provenance
  • Structured errors and graceful degradation

Boundary

SPIRT does not circumvent authentication, private profiles, platform protections, or rate limits.
